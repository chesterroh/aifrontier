<span class="paragraph-timestamp" data-ts="0:00">0:00</span> **卢正石** 今天录制节目是2026年11月7日，星期六早上。这一周可谓跌宕起伏。美国举行了中期选举，股市也大幅下跌。如果说FOMO是担心：“我是不是要错过这次机会了？得买股票。”反过来也有人担心：“啊，这次是不是彻底完了？得赶紧卖掉。”也有这样的情绪。而且资产市场和金融领域可能总有程序在运行，进一步加速这种趋势，所以市场似乎跌得非常厉害。这也让气氛不太好。

<span class="paragraph-timestamp" data-ts="0:38">0:38</span> 但如果问，这真的是AI泡沫的终结吗？完全不是。我反而觉得，也许只是稍微换了个挡，整个局面正迈向下一个阶段。我们之前谈到Anthropic的S-1 filing等事情时，说过营收正在下降，AI已进入编程领域，但进入其他知识工作领域的速度还不够快，谈过这些问题。

<span class="paragraph-timestamp" data-ts="1:06">1:06</span> 尽管如此，我们感觉很多企业，包括就业市场，对于朝这个方向发展的趋势，似乎都认为“这是必然会发生的事”。我是这么觉得的。所以，与其认为这一切已经结束，不如说接下来会发生更大的变化，现在正是换到二挡、真正的变革开始之时，我认为这样判断更恰当。

<span class="paragraph-timestamp" data-ts="1:41">1:41</span> 所以今天我会和胜准一起，过去几周我们一直在做偏人文方向的大型思想实验，今天就来看看市场上实际发生了哪些变化，梳理其中几个关键点。还会和钟贤一起探讨：如果智能体参与实际经济活动，会发生什么？已经有一些有趣的尝试、实验和公司，我们也会来看一看。那么胜准，发生了哪些事？


## 延期发布的 GPT-6.2 与 Fable 5.5：各方都在观望什么    *2:08*

<span class="paragraph-timestamp" data-ts="2:11">2:11</span> **崔胜准** 首先，这周，也就是今天凌晨，大家都很期待Astra，也就是GPT-6.2，或者Fable 5.5，总之期待会有新模型发布。但实际上并没有发布。所以大家就在想，为什么没发布？先说说这件事为什么重要。九月和十月在数学等方面取得成果的那个内部模型未必会原样发布，但现在差不多该有同一系谱的模型问世了。Sam Altman等人已经公开说过，可能会在十二月之前发布一次。

<span class="paragraph-timestamp" data-ts="2:41">2:41</span> 据说那个内部模型非常persistent，会坚持不懈地追求目标，甚至因此引发一些问题。也因此被认为擅长解数学等题目。大家原本期待这次用户终于能用上它，但结果没有发布。

<span class="paragraph-timestamp" data-ts="3:03">3:03</span> 之前传闻可是满天飞。连Thibault Sottiaux说了句奇怪的话，大家也做出各种离奇的解读，认为星期五终于要发布了。人们等了一整个凌晨，也就是在美国时间等到深夜，还是没等到。

<span class="paragraph-timestamp" data-ts="3:16">3:16</span> 当然，前一天GPT Cyber发布了，也发布了好几份文件。不过我看到Vals AI发了一条推文，大意是那些内部模型似乎存在一些安全问题，所以我们正在进行审查。那条推文表达的就是这个意思。

<span class="paragraph-timestamp" data-ts="3:37">3:37</span> 而且Astra连6.1都还没发布，对吧？Sol倒是6.1。但传闻说Astra会跳过6.1，直接发布6.2。之前6.1没有发布，也是因为未达到安全标准。所以当时也有新闻说，随着持续执行任务的能力增强，擅自行动的风险也随之增大。

<span class="paragraph-timestamp" data-ts="4:01">4:01</span> 恰好在11月4日，OpenAI发布了一份安全方面的文件。其中的关键也是“sandbagging”，就是明明有能力开展安全研究，却说自己做不到，拒绝去做。内部模型出现了这种欺骗行为，这些问题或许与此有关，让他们想发布，却暂时发布不了。

<span class="paragraph-timestamp" data-ts="4:25">4:25</span> 也可能并非这个原因，而是出于竞争和经济方面的考虑，双方都在观望时机。两边也有不少传闻说，Fable 5.5已经在接收路由过来的请求。从网上流传的消息看，有人说自己用过，还有人说它很厉害。

<span class="paragraph-timestamp" data-ts="4:41">4:41</span> OpenAI的GPT-6.2似乎也出现在某些模型服务里。当然，这些都只是传闻。所以我在想，双方是不是在盘算，谁先发布会占优势，还是会吃亏，因此都在试探、观望。所以我才把标题定为“互相观望的博弈”。总之，这周没有发布。

<span class="paragraph-timestamp" data-ts="5:01">5:01</span> **卢正石** 不过看来不久后确实会发布。

<span class="paragraph-timestamp" data-ts="5:05">5:05</span> **崔胜准** 对，我觉得会发布。而且现在也到了双方正面较量的时候。不过这周引发很多讨论的，是METR的报告。这是对Anthropic的AI研发加速情况所做的独立评估。

## 从 Claude 2.1 到 Sonnet 4.5：进步斜率翻倍    *7:47*

<span class="paragraph-timestamp" data-ts="7:47">7:47</span> **崔胜准** 用TL;DR概括这份报告，非常粗略地说，就是：从2023年10月到2025年10月，而这份报告完成的时间大概是2026年10月。也就是说，从Claude 2.1发展到Sonnet 4.5所取得的进步，在2025年10月至2026年10月这一年里又实现了一遍。也就是说，进步曲线的斜率大约翻了一倍。关键就在于斜率，归根结底是斜率的问题。

<span class="paragraph-timestamp" data-ts="8:17">8:17</span> 所以Ryan Greenblatt说，单看目前的情况，RSI就已经是个问题。他还说，看完这份报告后，自己必须修正原先的预测。再说Daniel Kokotajlo，他是《AI 2027》的作者之一，对吧？他原本是OpenAI的未来预测研究员，后来因某些原因离职，放弃了自己的股权，也是选择公开发声的人之一。

<span class="paragraph-timestamp" data-ts="8:45">8:45</span> Daniel Kokotajlo、Scott Alexander等人是在2024年初吗？大约4月发布了那份报告，预测AI到2027年会如何发展。最近这份报告又被频繁谈起，是因为他们预测的内容有80%以上如今正在应验。而且有些事情发生的速度甚至比他们预测的还快。

<span class="paragraph-timestamp" data-ts="9:09">9:09</span> 后来他们又……虽然参与的人有些变化，但Daniel Kokotajlo参与了今年《AI 2040》报告的制作团队……所以引发了不少关注，也出现了不少争论。这份报告在这个时候发布，确实有些巧。总之，按我的理解，市场上虽然有各种反应，但看完这份报告，又感觉热度被推高了……进步依然很快，所以我们得有所担忧。

## 算力激增与提前到来的 ASI 预测    *10:38*

## Simile 如何模拟人类的非理性选择    *44:28*

<span class="paragraph-timestamp" data-ts="44:28">44:28</span> **朴钟贤** 回到刚才的话题，我们来看看Simile这家公司。说到底，AI究竟能在多大程度上模仿人，这家公司又在描绘怎样的未来？

<span class="paragraph-timestamp" data-ts="44:38">44:38</span> **崔胜准** 那是一篇很有名的论文吧。是2023年吗？Smallville。

<span class="paragraph-timestamp" data-ts="44:46">44:46</span> **朴钟贤** Smallville，对。简单来说，就是用AI创建一群仿照真人的人物档案，再让他们在小镇里活动。某种意义上，这和我们现在运行Agent Market好像有点相似。不过，看看现在的AI，虽然AI在很多方面让人觉得像人，但也有不像人的地方。因为AI几乎完全是为了帮助人类而训练出来的。刚才我们也谈了很多RL：给它一道题，让它把题解好，alignment就是围绕这个目标做的。但人并不全是这样。人并不总做最有效率的选择。

<span class="paragraph-timestamp" data-ts="45:30">45:30</span> 所谓有人情味的选择，比如回家时，为了整理思绪，不坐出租车或公交车，而是特意步行，哪怕要花更长时间。人有时就会这样选择。AI只有连这样的选择都能做出，才能作为模拟人的工具来使用。但目前的AI在AI中实现，所以他们通过fine-tuning，努力让AI模仿这类人类行为。据说他们在这方面下了很大功夫。

<span class="paragraph-timestamp" data-ts="46:01">46:01</span> 所以，他们的很多工作都以访谈为基础。为了了解context，他们通过访谈收集数据，也收集问卷以及各类记录收集数据，再用这些数据构建一个模拟社会。运行模拟后，人们后来在现实中采取的行动应该都有记录可查。就看模拟结果与记录有多相似。

<span class="paragraph-timestamp" data-ts="46:25">46:25</span> 再进一步说，即使面对相同的情境，人也未必每次都采取相同的行动。尤其是在信息有限的情况下。所以，连人自身的行为都无法百分之百重现。某种程度上，人也算是一台概率机器吧。人的选择就是这样。将模拟结果与真实行为相比，看有多相似，连随机性也要比较。

<span class="paragraph-timestamp" data-ts="46:51">46:51</span> 这家公司就是在做这些事。以前他们通过对Qwen进行fine-tuning来构建这类模拟，使用了大约40万人的数据，还对每组1000人进行深度访谈，拿来比较。据说他们一直在做这类工作。总之，他们的目标是：假设地球上现在大约有80亿人，就把地球上所有人的行为都模拟出来。举个例子，假如美国政府要使用它，在做重大决策时，举个夸张的例子，比如拿伊朗战争来说。如果以某种方式进行战争，会对人们和社会产生什么影响？他们当然想先研究一下。据说他们想把它用在这样的场景中。

<span class="paragraph-timestamp" data-ts="47:37">47:37</span> 至于价格，我也只是听到过传闻。听说运行一次模拟收费很高，但财力雄厚的华尔街机构之类仍会委托他们。不过，官方似乎没有公布价格。看起来是签企业合同。似乎会根据规模等因素定制。那么，谁会使用这类服务呢？CVS Health？这样的美国医疗健康机构经常需要开展调查，如果能缩短调查时间，据说他们就想试试这类服务。

<span class="paragraph-timestamp" data-ts="48:19">48:19</span> 总之，为了提高模拟人类行为的准确度，人们也在努力。虽然方向与让AI更擅长编程等工作不同，但也在不断推进。我觉得这类技术今后还有很多用武之地。


## Robinhood 的 agentic trading：让个人拥有对冲基金级别的能力    *48:28*

<span class="paragraph-timestamp" data-ts="48:30">48:30</span> **朴钟贤** 接下来，我想举Robinhood的例子。我自己没用过Robinhood，只是听说过，稍微查了一下，据说它靠免佣金股票交易吸引了很多用户。所以可以把它看作一款面向消费者、供很多人交易股票的应用。这位创始人的采访，好像是前天还是昨天上传到 No Priors 的。他是 Robinhood 的创始人，他的故事在那期播客里也有谈到。苏联解体时，当地经历了严重的通货膨胀，他小时候亲身经历过，也见证了货币崩溃，原来他有这样的经历。
